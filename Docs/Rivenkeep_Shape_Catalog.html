1What This Doc Is

The complete, generated catalog of all 198 wall pieces — every one-sided polyomino (unique under rotation, not reflection) that fits inside a 4×4 box — grouped A–H, each shown in its home orientation with its ID and default name. It is a visual reference, generated algorithmically so it can never drift from the real piece set.

Where the design lives — this doc is the picture, not the rules

The piece design — the 8 groups, the 16-tier probability table, the deterministic-fair selection algorithm, and how pieces function as an engagement mechanism woven into the cognition curve — is owned by The Build Phase §7. The piece naming feature (buying naming rights, the moderation pipeline) is in the GDD. This doc holds the one thing those can only describe: the shapes themselves, and — below — the button that rotates the whole set so you can see how every piece reads at 0°/90°/180°/270°. A piece always starts in its catalog (0°) orientation in play, so this is the reference a seasoned player carries in their head.

2The 198 Shapes — Rotate the Whole Set

Colour-paired by cell count: A & B foundation + tetrominoes (1–4), C & D pentominoes (5), E & F hexominoes (6), G & H heptominoes (7). Mirror pairs sit side by side — there is no flip in play, so each mirror is a distinct piece. Hit the button to rotate every shape 90° clockwise, exactly as the rotation algorithm (Build §12) does in the Build tray.
