## Notes for the merge (no rule is proposed; each is a reading the unit relied on, or a finding)

1. **A15 readings this round uses, all already in §21.9.3:** *answer* (`MOUTH` with a runner back), *the world; measureless* (`EARTH{all}`), *the edge of the world* (`EARTH+EDGE{most}`), *flat* (`BENEATH+LIE`, `LIE+TREE×3`), *fewer* (`{few,more}`, read by the validator as "few more"), *for the moment … for always*, *if any … is left, then …*, *make sure* (`>TRUE`), *not leave out* (`!LOSE`), and *you (in the heart ring)* (`STONEFOLK×3` standing first on the file that holds you there; after the back-translation, ring 1's file 14).
2. **A19 (proposed) bit three times.** A memory ray names a file and a year and leaves the first cell's mark there, so the unit placed its remembered marks first or alone in their file-years: ring 11's "for always" rides on `WOOD` (the wood that holds the carving), because on our file the speech stands first; ring 21's first haven stands on file 2, so that `!HEAR#1` is alone on file 0; ring 23's "remembereth" is `ROOT+HOLD` (*ralthein*, §21.3), not `HOLD` with a ray, because the questioned green stands first on our file. If A19 is settled with a cell in the ray's address, rings 11 and 23 could take the old unit's cuts again.
3. **A ray on an act, with the blind** (ring 19, "We wist not why", a paragraph of its own): the act whose cause the wood does not hold (the oars turning back, ring 18) is cut again in the next ring with a ray to it (the same one), and the blind springs from the copy, because a runner may not cross a ring line inward. The validator reads it cleanly; worth a line in §6.1 if other leaves set a not-knowing alone.
4. **A20 in a man's face** (ring 18): the WHITE band of `STONEFOLK:crown` lies over his file's whole year, so his `EYE{only}` is in the white too. True of a face that looks; noted for the proposed A20 validator note.
5. **A16b, checked again.** Read with no `# file` comments, this round keeps *we* (file 12) from heart to bark only because the chip, `US×3‿`, stands first on the file in ring 1 and every later first mark of ours is an act or a belonging (ring 20 writes `!LOSE` before `SHAME`, ring 8 `GUIDE` before `SUMMER×3{all}`). Under A16 as the validator reads it, `SHAME` or `SUMMER×3{all}` first on file 12 would rename the file ("shame", "all summers"); A16b(b) would keep it. Files 9 and 11, which hold only bands, read by their bearings until A16b(d) is taken.
6. **A thing-sign first on a file names it, so name what the Book names** (the back-translation's lesson, twice): ring 1's file 14 began with `ROOT×3‿` and read "the forebears", not *your* forebears, until `STONEFOLK×3` was set before it; ring 12's file 1 began with a bare `CARVE` and read "a carving", not the carver, until `CARVE+US` (*sethea*, §21.3) was set before it.
7. **For a stricter blind test.** The blind reader of W01 found older and present Book wording in the spec's "Where" columns (§7.2, §8, §10.9, §21.9.2–3) and in this file. The rows added here name their rings and do not quote the Book; a later blind run could be given copies of both with the "Where" columns stripped.
