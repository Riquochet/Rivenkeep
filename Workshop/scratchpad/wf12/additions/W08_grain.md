**Findings for the validator** (not fixed: `grain_validate.py` is shared; none blocks the unit):
1. **A file that carries only a band is left out of the literal reading** (`--literal` prints files that hold marks): Thaesaen's harbour (STILL and WATER on file 2), the sea (file 14), the nights (Eirlenth's file 7, Neivaere's file 15), Eirlenth's white (file 4) appear only as a runner's target. *Proposed:* print a band-only file in its ring, "file f: the water (the sea), the band as a thing", so a blind reader meets the thing before the runner that reaches it.
2. **`>EYE` reads "the making of eye"**: the causative of a thing-class sign is read as a noun. A decoder wants "show" (make see), as A15's *show them themselves* says.
3. **`BURN{few,last}` reads "burn, few at the last"**: the fringe on a lone act that governs only an `OVER` beside it would read better noun-first, "a little fire, at the last" (as §21.9.6's finding 6).
